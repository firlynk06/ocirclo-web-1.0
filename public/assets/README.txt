Aset dari Figma (sudah terisi untuk demo):
  logo.png                 <- logo "circlo." (latar transparan)
  products/PRDxxx.png      <- foto produk, nama file = SKU. Baru ada: PRD001, PRD002, PRD003, PRD019.

  categories/*.png         <- gambar kategori di Consumer Home

Menambah foto produk: Figma -> klik gambar -> Export (PNG 2x) -> simpan sebagai products/<SKU>.png
